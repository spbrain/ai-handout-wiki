# Antigravity 크래딧 설정
기본적으로 pro이상 사용시에 기본 사용량이 막히면 주어진 기본 크래딧을 사용하서 연장해서 사용할수 있습니다. 
![](attachments/Pasted%20image%2020260403090955.png)

Open Antigravity User Settings 화면으로 들어갑니다.

왼쪽에 Models를 누르면 다음 화면이 나타납니다.
![](attachments/Pasted%20image%2020260403091030.png)

여기서 Enable AI Cridit Overages 를 사용으로 하시면 해당 크래딧을 사용해서 연장해서 사용할수 있습니다.(매 AI 구독 갱신시 초기화됨)
